# 📑 Detalhamento Preliminar

A Calculadora de IMC foi desenvolvida como uma aplicação web simples, com foco na prática dos conceitos fundamentais de desenvolvimento utilizando PHP.

A interface foi construída em HTML5 e estilizada com CSS3, proporcionando uma experiência de uso intuitiva. O usuário informa seu peso (em quilogramas) e sua altura (em metros) por meio de um formulário, que envia os dados para a própria página utilizando o método **GET**.

No processamento, o PHP recebe os valores informados, realiza a validação da existência dos dados e utiliza uma função específica para calcular o Índice de Massa Corporal (IMC). Após o cálculo, o resultado é arredondado para duas casas decimais e comparado com os intervalos definidos pela Organização Mundial da Saúde (OMS), permitindo identificar automaticamente a classificação correspondente.

O projeto foi estruturado de forma simples e organizada, separando a estilização (CSS) da lógica de processamento (PHP), facilitando a manutenção e futuras evoluções da aplicação.

Além de realizar o cálculo do IMC, este projeto teve como objetivo consolidar conhecimentos sobre formulários HTML, captura de dados com `$_GET`, funções, estruturas condicionais, validação de entrada e organização básica de aplicações web desenvolvidas em PHP.
